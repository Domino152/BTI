# 90-Second Demo Video Script

## Goal

Show that the prototype keeps the familiar NTA functionality while making the experience cleaner, faster, and more useful for students.

## Shot List And Voiceover

**0:00-0:08 - Opening**

Show the home page at `https://domino152.github.io/BTI/`.

Voiceover: "This is the rebuilt NTA citizen portal prototype: the same core public services, redesigned into a cleaner, more student-friendly experience."

**0:08-0:22 - Home And Notices**

Scroll through the compact hero carousel, quick cards, and Latest News panel.

Voiceover: "The home page brings key actions forward: mock tests, Abhyas practice, official notices, and exam discovery. The banner uses the supplied campaign images with smooth fading so it feels polished without wasting space."

**0:22-0:36 - Exams**

Open the Exams page and filter or scan categories.

Voiceover: "Students can browse NTA examinations by category, see official links, and quickly understand which exam belongs to which domain."

**0:36-0:48 - Public Pages**

Open About, RTI, Tender, Downloads, and Contact quickly.

Voiceover: "The public pages now follow one consistent visual language: clear headers, compact cards, readable spacing, and familiar government information architecture."

**0:48-1:02 - Login**

Register or sign in with username and password.

Voiceover: "The prototype includes real username and password authentication. Sessions are handled by the backend, and candidate data is tied to the signed-in account."

**1:02-1:18 - Candidate Workspace**

Show the student dashboard and application flow.

Voiceover: "Inside the candidate workspace, students can track exams, continue applications, review milestones, and move through the CUET UG application flow step by step."

**1:18-1:30 - Documents And Deployment**

Show document upload, then briefly show `/api/health`.

Voiceover: "Documents are stored in a private server folder, metadata lives in MongoDB, and the setup is ready for Railway backend hosting with a GitHub Pages frontend. It is a working prototype with a much more complete NTA-style user experience."
